| **Security Onion** | **Microsoft Sentinel** |
| --------- | ------------- |

| Gathers data by monitoring systems | Gathers data via data connectors |
| Stores data in Alerts, uses OQL for queries | Stores data in Log Analytics, uses KQL for queries |
